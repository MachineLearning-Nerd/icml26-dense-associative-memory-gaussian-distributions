# Audit report

This repository is an independent reproduction and claim audit for
**Dense associative memory for Gaussian distributions**.

The paper's Gaussian dense-associative-memory formulation, proof-level
capacity and decay claims, synthetic temperature separation, and recovered
Text8 protocol are supported under explicit scoped contracts. The exact v1
non-commuting one-step convergence statement is not supported: the
assumption-satisfying reproduction, independent checker, controls, and the
paper's own digitized Figure 8(b) reject it.

Read the detailed report at
[`reports/reproduction/report.md`](reports/reproduction/report.md), the
evaluator-facing release report at
[`candidate_space/pages/current/release-report.md`](candidate_space/pages/current/release-report.md),
and the version audit at
[`candidate_space/pages/current/version-audit.md`](candidate_space/pages/current/version-audit.md).

The branch roles and historical `orx/` to clean-name mapping are documented
in [`branch-audit.md`](branch-audit.md). Branch names describe evidence role;
they are not separate paper versions or author statements.
